# PetStore — Testes Manuais do Carrinho de Compras

Projeto prático de Quality Assurance (QA) realizado durante minha formação em QA Engineering pela Mate Academy.

O objetivo da atividade foi analisar os requisitos do carrinho de compras da aplicação PetStore, elaborar cenários de teste, executar verificações funcionais e documentar os resultados encontrados.

## Ferramentas e conhecimentos utilizados

* Testes manuais de aplicações Web
* Análise de requisitos
* Checklists e casos de teste
* Técnicas de testes positivos e negativos
* Ciclo de Vida de Testes de Software (STLC)
* Documentação de resultados e relatórios de bugs

## Escopo dos testes

As verificações do carrinho abordaram funcionalidades como:

* Adição de produtos ao carrinho.
* Remoção de produtos.
* Atualização da quantidade de itens.
* Validação de preço e subtotal.
* Comportamento do carrinho com quantidade zero.
* Verificações relacionadas à disponibilidade de estoque.
* Informações e links apresentados no carrinho.
* Navegação para o checkout.
* Atualização do indicador de quantidade de itens.
* Comportamento do carrinho durante a sessão do usuário.

## Atividades realizadas

1. Análise dos requisitos funcionais do carrinho.
2. Decomposição das funcionalidades em cenários de teste.
3. Elaboração de checklist com verificações positivas e negativas.
4. Execução dos testes e registro dos resultados.
5. Identificação de situações que exigiam verificações adicionais.
6. Organização da documentação para apresentação e revisão.

## Documentação e evidências

Os documentos originais, checklists e evidências disponíveis serão adicionados gradualmente a este repositório.
